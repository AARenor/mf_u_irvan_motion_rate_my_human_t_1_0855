This is a small Python 3.13 program (standard library only, no network) that writes one short text — the single line its agent would post about its human on a rating site — for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`, saving it as `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (or `/output` when unset), creating that folder if needed and writing the bytes with no trailing newline.
